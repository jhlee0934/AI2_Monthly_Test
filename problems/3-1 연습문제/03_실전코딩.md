## 문제 1. CIFAR-10 선형 프로빙 학습기

ImageNet 사전학습 ResNet18을 이용해 CIFAR-10 선형 프로빙 학습과 평가를 수행하는 `run_linear_probe`를 구현하라.

## 요구사항

- 함수는 이미 만들어진 `train_loader`, `test_loader`, `device`를 입력받는다.
- 특징 추출기 전체를 동결하고 10클래스 분류 헤드만 학습한다.
- 손실 함수는 교차 엔트로피, 옵티마이저는 `SGD(lr=0.001, momentum=0.9)`를 사용한다.
- `StepLR(step_size=2, gamma=0.1)`을 에폭 단위로 적용한다.
- 매 에폭의 평균 손실을 리스트에 저장한다. 마지막 배치 크기가 다를 수 있음을 고려한다.
- 평가에는 `eval()`과 `no_grad()`를 모두 사용한다.
- `{"model": model, "losses": losses, "accuracy": accuracy}`를 반환한다. 정확도는 0~100의 실수다.

## 제공 코드 또는 스켈레톤

## 정답 1

## 정답 코드

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision.models import resnet18, ResNet18_Weights

def run_linear_probe(train_loader, test_loader, device, epochs=5):
    model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)
    for parameter in model.parameters():
        parameter.requires_grad = False
    model.fc = nn.Linear(model.fc.in_features, 10)
    model.to(device)

    criterion = nn.CrossEntropyLoss()
    optimizer = optim.SGD(model.fc.parameters(), lr=0.001, momentum=0.9)
    scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=2, gamma=0.1)
    losses = []

    for _ in range(epochs):
        model.train()
        loss_sum = 0.0
        sample_count = 0
        for images, labels in train_loader:
            images, labels = images.to(device), labels.to(device)
            optimizer.zero_grad()
            logits = model(images)
            loss = criterion(logits, labels)
            loss.backward()
            optimizer.step()
            batch_size = labels.size(0)
            loss_sum += loss.item() * batch_size
            sample_count += batch_size
        losses.append(loss_sum / sample_count)
        scheduler.step()

    model.eval()
    correct = total = 0
    with torch.no_grad():
        for images, labels in test_loader:
            images, labels = images.to(device), labels.to(device)
            predictions = model(images).argmax(dim=1)
            total += labels.size(0)
            correct += predictions.eq(labels).sum().item()

    return {"model": model, "losses": losses, "accuracy": 100.0 * correct / total}
```

## 핵심 해설

- 사전학습 모델 출력 헤드의 입력 차원을 보존해 새 헤드를 연결하고, 새 헤드만 옵티마이저에 전달한다.
- 배치 평균 손실에 실제 배치 크기를 곱해 누적한 뒤 전체 샘플 수로 나눠야 마지막 불완전 배치도 정확히 반영된다.
- 학습 블록은 `zero_grad → forward → loss → backward → step`, 에폭 종료 후 `scheduler.step` 순서다.
- 클래스 수를 바꾸면 헤드 출력 수를, 미세조정 범위를 넓히면 동결 상태와 옵티마이저 입력을 함께 변경한다.

## 문제 2. 증강과 부분 파인튜닝 구성기

CIFAR-10용 전처리, DataLoader, 부분 파인튜닝 모델, 최적화 도구를 생성하는 `build_partial_finetuning`을 구현하라.

## 요구사항

- 학습 전처리 순서는 `RandomResizedCrop(224)`, `RandomHorizontalFlip(0.5)`, `RandomRotation(15)`, `ColorJitter(0.2, 0.2, 0.2)`, `ToTensor`, `Normalize`다.
- 평가는 `Resize(256)`, `CenterCrop(224)`, `ToTensor`, `Normalize` 순서이며 랜덤 변환을 사용하지 않는다.
- 정규화 평균과 표준편차는 `ResNet18_Weights.IMAGENET1K_V1.transforms()`에서 얻는다.
- 학습/테스트 DataLoader의 배치 크기는 256이며 학습 데이터만 섞는다.
- ResNet18의 헤드를 10클래스로 교체하고 `layer4`, `fc`만 학습 가능하게 한다.
- 옵티마이저는 학습 가능한 파라미터만 받는 `SGD(lr=0.0005, momentum=0.9)`다.
- 반환 딕셔너리는 `model`, `train_loader`, `test_loader`, `criterion`, `optimizer`, `scheduler` 키를 가진다.

```python
import torch.nn as nn
import torch.optim as optim
import torchvision
from torch.utils.data import DataLoader
from torchvision import transforms
from torchvision.models import resnet18, ResNet18_Weights

def build_partial_finetuning(data_root="../data"):
    weights = ResNet18_Weights.IMAGENET1K_V1
    spec = weights.transforms()
    train_transform = transforms.Compose([
        transforms.RandomResizedCrop(224),
        transforms.RandomHorizontalFlip(p=0.5),
        transforms.RandomRotation(15),
        transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2),
        transforms.ToTensor(),
        transforms.Normalize(mean=spec.mean, std=spec.std),
    ])
    test_transform = transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize(mean=spec.mean, std=spec.std),
    ])

    train_set = torchvision.datasets.CIFAR10(data_root, train=True, download=True, transform=train_transform)
    test_set = torchvision.datasets.CIFAR10(data_root, train=False, download=True, transform=test_transform)
    train_loader = DataLoader(train_set, batch_size=256, shuffle=True, num_workers=2)
    test_loader = DataLoader(test_set, batch_size=256, shuffle=False, num_workers=2)

    model = resnet18(weights=weights)
    model.fc = nn.Linear(model.fc.in_features, 10)
    for parameter in model.parameters():
        parameter.requires_grad = False
    for parameter in model.layer4.parameters():
        parameter.requires_grad = True
    for parameter in model.fc.parameters():
        parameter.requires_grad = True

    criterion = nn.CrossEntropyLoss()
    optimizer = optim.SGD(
        filter(lambda parameter: parameter.requires_grad, model.parameters()),
        lr=0.0005,
        momentum=0.9,
    )
    scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=5, gamma=0.1)
    return {
        "model": model,
        "train_loader": train_loader,
        "test_loader": test_loader,
        "criterion": criterion,
        "optimizer": optimizer,
        "scheduler": scheduler,
    }
```

## 핵심 해설

- 데이터셋은 원본 이미지를 보관하고, 조회 시 지정된 transform의 출력을 DataLoader에 넘긴다.
- 학습 입력은 매 조회마다 달라질 수 있지만 테스트 입력은 결정적이다. 두 입력 모두 사전학습 분포와 같은 정규화를 사용한다.
- 전체 동결 뒤 선택한 블록만 해제하면 범위를 명확히 통제할 수 있다.
- 전체 파인튜닝 조건으로 변경되면 모든 파라미터를 해제하고 옵티마이저 입력을 `model.parameters()`로 바꾼다.

```python
import torch
from datasets import load_dataset
from transformers import ViTForImageClassification, ViTImageProcessor

def classify_cifar10(indices):
    if not indices:
        return []

    checkpoint = "nateraw/vit-base-patch16-224-cifar10"
    dataset = load_dataset("uoft-cs/cifar10", split="test")
    label_names = dataset.features["label"].names
    images = [dataset[index]["img"] for index in indices]
    actual_ids = [dataset[index]["label"] for index in indices]

    processor = ViTImageProcessor.from_pretrained(checkpoint)
    model = ViTForImageClassification.from_pretrained(checkpoint)
    model.eval()

    inputs = processor(images=images, return_tensors="pt")
    with torch.no_grad():
        logits = model(**inputs).logits
    predicted_ids = logits.argmax(dim=-1).tolist()

    return [
        {
            "index": index,
            "predicted": label_names[predicted_id],
            "actual": label_names[actual_id],
        }
        for index, predicted_id, actual_id in zip(indices, predicted_ids, actual_ids)
    ]
```

## 핵심 해설

- 데이터셋 항목은 `{"img": PIL.Image, "label": int}` 형식이고, `features["label"].names`가 정수 라벨을 이름으로 바꾼다.
- 이미지 리스트 → processor의 `pixel_values` 배치 → 모델의 `logits` → 클래스별 `argmax`로 데이터가 전달된다.
- `**inputs`는 전처리 딕셔너리를 모델의 키워드 인자로 전달한다.
- 체크포인트나 데이터셋이 바뀌면 전처리기·모델·라벨 매핑을 함께 확인해야 한다. 고수준 출력만 필요하면 `pipeline("image-classification", model=checkpoint)`로 전처리부터 후처리까지 대체할 수 있다.
