## 문제 1. ResNet18 선형 프로빙

## 정답 1

- `(A)` 모델의 기존 모든 파라미터 동결
- `(B)` `model.fc`를 입력 특징 수를 보존한 10출력 `nn.Linear`로 교체
- `(C)` 로짓과 정수 라벨을 받는 `nn.CrossEntropyLoss` 생성
- `(D)` 새 분류 헤드의 파라미터만 받는 옵티마이저와 에폭 기반 스케줄러 생성
- `(E)` 에폭이 끝난 뒤 `scheduler.step()` 호출
- `(F)` `model.eval()`과 `torch.no_grad()`를 사용해 테스트 정확도 계산

## 정답 코드

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision.models import resnet18, ResNet18_Weights

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)

for param in model.parameters():
    param.requires_grad = False
model.fc = nn.Linear(model.fc.in_features, 10)
model.to(device)

criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.fc.parameters(), lr=0.001, momentum=0.9)
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=2, gamma=0.1)

epochs = 5
for _ in range(epochs):
    model.train()
    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)
        optimizer.zero_grad()
        logits = model(images)
        loss = criterion(logits, labels)
        loss.backward()
        optimizer.step()
    scheduler.step()

model.eval()
correct = total = 0
with torch.no_grad():
    for images, labels in test_loader:
        images, labels = images.to(device), labels.to(device)
        predictions = model(images).argmax(dim=1)
        total += labels.size(0)
        correct += predictions.eq(labels).sum().item()
print(f"test_accuracy={100 * correct / total:.2f}%")
```

## 핵심 해설

- 모델 로드 → 동결 → 헤드 교체 → 전처리/데이터 → 손실/최적화 → 학습 → 평가 순서다.
- `model.fc.in_features`는 특징 추출기의 출력 차원이고, 새 `Linear`의 출력은 클래스별 로짓 10개다.
- `CrossEntropyLoss`에는 softmax 확률이 아니라 `(배치, 10)` 로짓과 `(배치,)` 정수 라벨을 전달한다.
- 동결 후 새로 생성한 `model.fc`는 기본적으로 `requires_grad=True`이므로 `model.fc.parameters()`만 옵티마이저에 전달할 수 있다.
- 클래스 수가 바뀌면 분류 헤드의 출력 수를, 학습 범위가 바뀌면 동결 설정과 옵티마이저의 파라미터 대상을 수정한다.

## 문제 2. 데이터 증강과 선택적 파인튜닝

ResNet18의 `layer4`와 새 분류 헤드만 CIFAR-10에 맞게 파인튜닝한다. 아래 흐름의 빈칸 `(A)`~`(F)`에 필요한 처리 블록을 작성하라.

`가중치 메타데이터 로드 → (A) → (B) → 학습/평가 데이터셋 구성 → (C) → 분류 헤드 교체 → (D) → (E) → 학습 및 검증 → (F)`

## 요구사항

- 학습 데이터에만 랜덤 크롭, 좌우 반전, 회전, 색상 변형을 적용한다.
- 평가 데이터에는 결정적인 리사이즈와 중앙 크롭만 적용한다.
- 두 파이프라인 모두 사전학습 가중치의 평균과 표준편차로 정규화한다.
- `layer4`와 `fc`만 업데이트한다.
- `StepLR`은 에폭마다, `ReduceLROnPlateau`를 선택한다면 검증 손실을 전달해 갱신한다.

## 정답 2

- `(A)` 랜덤 증강을 포함하는 학습 전처리 구성
- `(B)` 랜덤 요소가 없는 평가 전처리 구성
- `(C)` 두 데이터셋에 서로 다른 transform을 연결하고 DataLoader 생성
- `(D)` 전체 파라미터를 동결한 뒤 `layer4`와 `fc`만 동결 해제
- `(E)` `requires_grad=True`인 파라미터만 옵티마이저에 전달
- `(F)` 스케줄러 종류에 맞는 시점과 입력으로 학습률 갱신

## 정답 코드

```python
import torch.nn as nn
import torch.optim as optim
import torchvision
from torch.utils.data import DataLoader
from torchvision import transforms
from torchvision.models import resnet18, ResNet18_Weights

weights = ResNet18_Weights.IMAGENET1K_V1
preprocess = weights.transforms()

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2),
    transforms.ToTensor(),
    transforms.Normalize(mean=preprocess.mean, std=preprocess.std),
])
eval_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=preprocess.mean, std=preprocess.std),
])

train_set = torchvision.datasets.CIFAR10("../data", train=True, download=True, transform=train_transform)
test_set = torchvision.datasets.CIFAR10("../data", train=False, download=True, transform=eval_transform)
train_loader = DataLoader(train_set, batch_size=256, shuffle=True, num_workers=2)
test_loader = DataLoader(test_set, batch_size=256, shuffle=False, num_workers=2)

model = resnet18(weights=weights)
model.fc = nn.Linear(model.fc.in_features, 10)
for parameter in model.parameters():
    parameter.requires_grad = False
for parameter in model.layer4.parameters():
    parameter.requires_grad = True
for parameter in model.fc.parameters():
    parameter.requires_grad = True

optimizer = optim.SGD(
    filter(lambda parameter: parameter.requires_grad, model.parameters()),
    lr=0.0005,
    momentum=0.9,
)
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=5, gamma=0.1)
# 각 에폭의 배치 학습 및 검증을 수행한 뒤:
scheduler.step()
```

## 핵심 해설

- 원본 PIL 이미지가 데이터셋의 `transform`을 거쳐 `(3, 224, 224)` 텐서가 되고 DataLoader가 이를 배치로 묶는다.
- 증강은 학습 표본의 변형을 매번 바꾸지만 평가는 같은 입력에 같은 결과가 나와야 하므로 랜덤 변환을 쓰지 않는다.
- `filter(lambda p: p.requires_grad, model.parameters())`는 학습 대상 파라미터만 순회 가능한 객체로 전달한다.
- 전체 파인튜닝으로 바꾸려면 모든 파라미터를 `True`로 설정하고 `model.parameters()`를 옵티마이저에 전달한다.
- `ReduceLROnPlateau`로 바꾸면 `scheduler.step(validation_loss)`를 호출해야 하며, 일반 `StepLR`에는 지표를 전달하지 않는다.

## 문제 3. Hugging Face ViT 추론

CIFAR-10으로 파인튜닝된 ViT 체크포인트를 사용해 여러 PIL 이미지를 분류한다. 다음 처리 흐름의 빈칸 `(A)`~`(E)`를 채워라.

`CIFAR-10 test split 로드 → 라벨 이름 추출 → (A) → (B) → (C) → 이미지 목록 전처리 → (D) → (E) → 사람이 읽을 수 있는 결과 출력`

## 요구사항

- 전처리기와 모델은 같은 체크포인트를 사용한다.
- 전처리 결과를 PyTorch 텐서 딕셔너리로 받는다.
- 한 번의 순전파로 이미지 여러 장을 처리한다.
- 추론 시 기울기를 기록하지 않는다.
- 각 이미지의 최대 로짓 인덱스를 클래스 이름으로 변환한다.

## 정답 3

- `(A)` `ViTImageProcessor.from_pretrained`로 전처리기 로드
- `(B)` `ViTForImageClassification.from_pretrained`로 분류 모델 로드
- `(C)` 모델을 평가 모드로 전환
- `(D)` `torch.no_grad()` 안에서 전처리 딕셔너리를 키워드 인자로 언패킹해 순전파
- `(E)` `outputs.logits.argmax(dim=-1)`로 배치별 예측 클래스 산출

## 정답 코드

```python
import torch
from datasets import load_dataset
from transformers import ViTForImageClassification, ViTImageProcessor

checkpoint = "nateraw/vit-base-patch16-224-cifar10"
dataset = load_dataset("uoft-cs/cifar10", split="test")
label_names = dataset.features["label"].names

processor = ViTImageProcessor.from_pretrained(checkpoint)
model = ViTForImageClassification.from_pretrained(checkpoint)
model.eval()

indices = [0, 100, 200, 300, 400]
images = [dataset[index]["img"] for index in indices]
inputs = processor(images=images, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)
predictions = outputs.logits.argmax(dim=-1).tolist()

for index, prediction in zip(indices, predictions):
    print(index, label_names[prediction])
```

## 핵심 해설

- `processor`는 PIL 이미지 리스트를 받아 최소한 `pixel_values` 키를 가진 텐서 딕셔너리를 반환한다.
- `model(**inputs)`는 이 딕셔너리를 `model(pixel_values=...)` 형태로 전달하며, 출력 객체의 `logits` 모양은 `(이미지 수, 클래스 수)`다.
- `argmax(dim=-1)`은 각 행의 클래스 차원에서 가장 큰 로짓의 인덱스를 고른다.
- 모델을 바꾸면 전처리기도 같은 체크포인트로 바꿔야 한다. 단일 이미지라면 `images=image`, 고수준 API를 쓰려면 `pipeline("image-classification", model=checkpoint)`로 해당 블록 전체를 대체할 수 있다.
