## 문제 1. 미니 BPE 학습기

## 요구사항

- `train_bpe(vocab, num_merges)`를 구현하라.
- `vocab`은 `{"l o w </w>": 5, ...}`처럼 공백으로 심볼을 구분한 문자열을 키로, 빈도를 값으로 갖는다.
- 각 단계마다 모든 단어의 인접 심볼 쌍 빈도를 단어 빈도로 가중하여 합산한다.
- 최빈 쌍을 공백 경계에서만 병합한다.
- 반환값은 `(병합된 vocab, 병합 이력)`이며 이력 원소는 `(왼쪽 심볼, 오른쪽 심볼)` 튜플이다.
- 입력 딕셔너리를 직접 변경하지 않는다. 동률이면 딕셔너리를 순회하며 먼저 발견된 쌍을 선택해도 된다.

## 제공 코드 또는 스켈레톤

vocab = {"l o w </w>": 5, "l o w e r </w>": 2, "n e w </w>": 6}

print(merges)
print(trained_vocab)

- `len(merges)`는 병합 가능한 쌍이 충분하면 5이다.
- 반환된 모든 빈도의 합은 입력 빈도의 합 13과 같다.

```python
import re

def pair_frequencies(vocab):
    frequencies = {}
    for word, word_frequency in vocab.items():
        symbols = word.split()
        for left, right in zip(symbols, symbols[1:]):
            pair = (left, right)
            frequencies[pair] = frequencies.get(pair, 0) + word_frequency
    return frequencies

def merge_pair(vocab, pair):
    separated = re.escape(" ".join(pair))
    pattern = re.compile(r"(?<!\S)" + separated + r"(?!\S)")
    return {
        pattern.sub("".join(pair), word): frequency
        for word, frequency in vocab.items()
    }

def train_bpe(vocab, num_merges):
    result = dict(vocab)
    history = []
    for _ in range(num_merges):
        frequencies = pair_frequencies(result)
        if not frequencies:
            break
        best_pair = max(frequencies, key=frequencies.get)
        result = merge_pair(result, best_pair)
        history.append(best_pair)
    return result, history

vocab = {"l o w </w>": 5, "l o w e r </w>": 2, "n e w </w>": 6}
trained_vocab, merges = train_bpe(vocab, 5)
print(merges)
print(trained_vocab)
assert len(merges) == 5
assert sum(trained_vocab.values()) == 13
```

## 핵심 해설

- 흐름은 전체 쌍 빈도 집계 → 최빈 쌍 결정 → 모든 단어에서 병합 → 지정 횟수 반복이다.
- 쌍 빈도 딕셔너리의 키는 문자열이 아니라 길이 2의 튜플이다.
- 병합 함수 출력이 다음 반복의 입력이 된다. 병합 횟수 조건은 `num_merges`만 바꾸면 된다.
- `re.escape`와 lookaround가 부분 문자열의 잘못된 병합을 막는다.

```python
import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader

samples = [([2, 7, 9, 3], 1), ([2, 5, 3], 0), ([2, 8, 8, 6, 3], 1)]

class ReviewDataset(Dataset):
    def __init__(self, samples, max_length=6):
        self.samples = [(ids[:max_length], label) for ids, label in samples]

    def __len__(self):
        return len(self.samples)

    def __getitem__(self, index):
        return self.samples[index]

def pad_batch(batch):
    ids_list, labels = zip(*batch)
    length = max(len(ids) for ids in ids_list)
    padded = [ids + [0] * (length - len(ids)) for ids in ids_list]
    return torch.tensor(padded, dtype=torch.long), torch.tensor(labels)

class RNNClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=8, hidden_dim=16):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True)
        self.output = nn.Linear(hidden_dim, 1)

    def forward(self, input_ids):
        _, hidden = self.rnn(self.embedding(input_ids))
        return self.output(hidden[-1]).squeeze(-1)

loader = DataLoader(
    ReviewDataset(samples), batch_size=3, shuffle=True, collate_fn=pad_batch
)
model = RNNClassifier(vocab_size=10)
criterion = nn.BCEWithLogitsLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

input_ids, labels = next(iter(loader))
optimizer.zero_grad()
logits = model(input_ids)
loss = criterion(logits, labels.float())
loss.backward()
optimizer.step()
print(input_ids.shape, logits.shape, loss.item())
```

## 핵심 해설

- Dataset 출력의 리스트를 `collate_fn`이 `(B,L)` LongTensor로 바꾸고, 모델이 이를 `(B,)` 로짓으로 바꾼다.
- BCE는 float 정답을 요구한다. 확률이 필요할 때만 추론 후 `torch.sigmoid(logits)`를 호출한다.
- 클래스가 3개 이상이면 Linear 출력, 레이블 dtype, 손실을 각각 `num_classes`, long, `CrossEntropyLoss`로 바꾼다.

## 문제 3. PAD 마스크를 적용한 LSTM Attention 분류기

## 요구사항

- `input_ids` shape는 `(B,L)`, PAD ID는 0이다.
- Embedding → LSTM → Luong dot attention → 분류 순서로 구현한다.
- 마지막 층의 LSTM hidden을 query로 사용한다.
- PAD 위치의 attention score는 softmax 전에 제외한다.
- 반환값은 클래스 로짓 `(B,C)`와 attention weight `(B,L)`이다.
- query와 context를 이어 붙여 분류하며 dropout 확률은 0.3이다.

```python
import torch
from torch import nn

class MaskedLuongAttention(nn.Module):
    def forward(self, query, values, mask):
        scores = torch.bmm(values, query.unsqueeze(-1)).squeeze(-1)
        scores = scores.masked_fill(~mask, torch.finfo(scores.dtype).min)
        weights = torch.softmax(scores, dim=1)
        context = torch.bmm(weights.unsqueeze(1), values).squeeze(1)
        return context, weights

class AttentionClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.attention = MaskedLuongAttention()
        self.dropout = nn.Dropout(0.3)
        self.output = nn.Linear(hidden_dim * 2, num_classes)

    def forward(self, input_ids):
        mask = input_ids.ne(0)
        values, (hidden, _) = self.lstm(self.embedding(input_ids))
        query = hidden[-1]
        context, weights = self.attention(query, values, mask)
        features = torch.cat((query, context), dim=-1)
        return self.output(self.dropout(features)), weights

model = AttentionClassifier(20, 8, 16, 2)
x = torch.tensor([[2, 5, 3, 0], [2, 8, 6, 3]])
logits, weights = model(x)
print(logits.shape, weights.shape, weights)
assert weights[0, 3].item() == 0.0
assert torch.allclose(weights.sum(1), torch.ones(2))
```

## 핵심 해설

- Boolean mask `(B,L)`는 score와 같은 shape이며 `False`인 PAD 위치를 매우 작은 값으로 바꾼다.
- softmax 뒤 PAD 가중치는 0이 되고 유효 토큰 가중치 합은 1이다.
- `values`와 `query`가 같은 hidden 차원이므로 별도 투영 없는 dot attention이 가능하다. 차원이 다르면 query 투영층을 추가한다.

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

def predict_sentiment(
    texts,
    model_name="distilbert-base-uncased-finetuned-sst-2-english",
):
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSequenceClassification.from_pretrained(model_name)
    inputs = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")
    model.eval()
    with torch.no_grad():
        logits = model(**inputs).logits
    probabilities = torch.softmax(logits, dim=-1)
    scores, class_ids = probabilities.max(dim=-1)
    return [
        {"label": model.config.id2label[class_id.item()], "score": score.item()}
        for class_id, score in zip(class_ids, scores)
    ]

print(predict_sentiment(["I love it.", "I hate it."]))
```

## 핵심 해설

- tokenizer는 문자열 리스트를 받아 `input_ids`와 `attention_mask`를 포함한 배치 매핑을 반환한다.
- `padding=True`는 배치 최장 길이에 맞추고 `truncation=True`는 모델 최대 길이 초과를 방지한다.
- GPU를 쓰려면 모델과 매핑의 모든 텐서를 같은 device로 이동하는 블록을 추가한다.

## 문제 5. 토큰·위치 임베딩과 Pre-LN Transformer 블록

## 요구사항

- `TransformerEmbedding`은 토큰 ID `(B,L)`를 받아 토큰 임베딩과 위치 임베딩을 더한 `(B,L,H)`를 반환한다.
- 위치 ID는 입력과 같은 장치에 생성한다.

- attention은 `batch_first=True`이고 입력·출력 shape를 유지한다.

## 정답 코드

```python
import torch
from torch import nn

class TransformerEmbedding(nn.Module):
    def __init__(self, vocab_size, hidden_dim, max_length):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, hidden_dim)
        self.position_embedding = nn.Embedding(max_length, hidden_dim)

    def forward(self, input_ids):
        batch_size, length = input_ids.shape
        positions = torch.arange(length, device=input_ids.device)
        positions = positions.unsqueeze(0).expand(batch_size, length)
        return self.token_embedding(input_ids) + self.position_embedding(positions)

class PreLNBlock(nn.Module):
    def __init__(self, hidden_dim, num_heads, ff_dim):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_dim)
        self.attention = nn.MultiheadAttention(
            hidden_dim, num_heads, batch_first=True
        )
        self.norm2 = nn.LayerNorm(hidden_dim)
        self.ffn = nn.Sequential(
            nn.Linear(hidden_dim, ff_dim),
            nn.GELU(),
            nn.Linear(ff_dim, hidden_dim),
        )

    def forward(self, x):
        normalized = self.norm1(x)
        attended, _ = self.attention(normalized, normalized, normalized)
        x = x + attended
        x = x + self.ffn(self.norm2(x))
        return x

ids = torch.randint(0, 100, (2, 7))
x = TransformerEmbedding(100, 32, 16)(ids)
y = PreLNBlock(32, 4, 128)(x)
print(x.shape, y.shape)
```

## 핵심 해설

- 토큰 ID와 위치 ID는 각각 `(B,L)`이고 두 Embedding 출력 `(B,L,H)`를 원소별로 더한다.
- self-attention에서는 query, key, value에 같은 정규화 결과를 전달한다.
- `hidden_dim`은 `num_heads`로 나누어떨어져야 한다.
- 최대 입력 길이가 늘면 위치 임베딩의 `max_length`, 모델 폭이 바뀌면 embedding과 block의 `hidden_dim`을 함께 수정한다.
- decoder-only causal attention으로 바꾸려면 attention 호출에 미래 위치를 가리는 마스크를 전달한다.
