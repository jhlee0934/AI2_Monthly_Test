## 문제 1. BPE 학습과 WordPiece 토크나이저 생성

문자 단위로 분리된 빈도 사전에서 BPE 병합을 5회 수행한 뒤, 별도의 한국어 말뭉치로 WordPiece 토크나이저를 학습하는 흐름이다. 다음 ㉠~㉣에 들어갈 처리 블록을 순서대로 작성하라.

## 요구사항

- 인접 심볼 쌍의 빈도에는 각 단어의 등장 빈도를 반영한다.
- 매 반복에서 빈도가 가장 높은 쌍 하나를 고르고 토큰 경계에서만 병합한다.
- WordPiece는 어휘 30,000개, 최소 빈도 2, 알파벳 제한 6,000을 사용한다.
- 특수 토큰 순서는 `[PAD]`, `[UNK]`, `[CLS]`, `[SEP]`, `[MASK]`이다.

## 제공 코드 또는 스켈레톤

```python
vocab = {"l o w </w>": 5, "l o w e r </w>": 2, "n e w </w>": 6}

㉠ 인접 심볼 쌍과 가중 빈도 집계
for _ in range(5):
    ㉡ 최고 빈도 쌍 선택
    ㉢ 선택한 쌍을 토큰 경계에서 병합하여 vocab 갱신

㉣ naver_review.txt로 WordPiece 학습
```

## 정답 코드

```python
import re
from tokenizers import BertWordPieceTokenizer

def get_stats(vocab):
    pairs = {}
    for word, freq in vocab.items():
        symbols = word.split()
        for i in range(len(symbols) - 1):
            pair = (symbols[i], symbols[i + 1])
            pairs[pair] = pairs.get(pair, 0) + freq
    return pairs

def merge_vocab(pair, vocab):
    pattern = re.compile(r"(?<!\S)" + re.escape(" ".join(pair)) + r"(?!\S)")
    return {
        pattern.sub("".join(pair), word): freq
        for word, freq in vocab.items()
    }

vocab = {"l o w </w>": 5, "l o w e r </w>": 2, "n e w </w>": 6}
for _ in range(5):
    stats = get_stats(vocab)
    best = max(stats, key=stats.get)
    vocab = merge_vocab(best, vocab)

tokenizer = BertWordPieceTokenizer(lowercase=False, strip_accents=False)
tokenizer.train(
    files=["naver_review.txt"],
    vocab_size=30_000,
    min_frequency=2,
    limit_alphabet=6_000,
    special_tokens=["[PAD]", "[UNK]", "[CLS]", "[SEP]", "[MASK]"],
    wordpieces_prefix="##",
)
print(tokenizer.get_vocab_size())
```

## 핵심 해설

- 실행 순서는 쌍 집계 → 최빈 쌍 선택 → 병합 → 반복 → WordPiece 학습이다.
- `get_stats`는 `{공백으로 분리된 단어: 등장 빈도}`를 받아 `{(심볼1, 심볼2): 가중 빈도}`를 반환한다.
- `re.escape`는 `</w>` 같은 문자를 정규식 메타 문자로 해석하지 않게 한다. 앞뒤 lookaround는 심볼 경계를 보장한다.
- `train`의 `files`는 문자열 경로의 리스트다. 말뭉치가 여러 개면 이 리스트만 늘리면 된다.
- 병합 횟수 변경은 반복 횟수, WordPiece 사전 크기 변경은 `vocab_size`를 수정한다.

## 문제 2. NSMC에서 RNN 감성 분류까지

`ratings.txt`를 사용해 RNN 이진 감성 분류기를 학습한다. 아래 흐름의 ㉠~㉤을 완성하라.

## 요구사항

- `document` 결측 행을 제거하고 레이블 비율을 유지해 8:2로 분리한다.
- 각 문장은 WordPiece ID 최대 64개로 자른다.
- 배치 안의 최장 문장에 맞춰 `[PAD]`의 ID 0으로 패딩한다.
- 모델 출력은 샘플마다 로짓 하나이며 손실 함수 안에서 sigmoid가 처리되어야 한다.

## 제공 코드 또는 스켈레톤

```text
ratings.txt
  → ㉠ 정제 및 층화 분할
  → ㉡ Dataset: 문장 → ID 리스트
  → ㉢ collate_fn: 동적 패딩 → (input_ids, labels)
  → ㉣ Embedding → RNN → 마지막 hidden → Linear
  → ㉤ 학습: 로짓과 레이블로 손실 계산 → 역전파 → 갱신
```

```python
import pandas as pd
import torch
from sklearn.model_selection import train_test_split
from tokenizers import BertWordPieceTokenizer
from torch import nn
from torch.utils.data import Dataset, DataLoader

tokenizer = BertWordPieceTokenizer(
    "naver_wp-vocab.txt", lowercase=False, strip_accents=False
)
df = pd.read_csv("ratings.txt", sep="\t").dropna(subset=["document"])
train_df, test_df = train_test_split(
    df, test_size=0.2, random_state=42, stratify=df["label"]
)

class NSMCDataset(Dataset):
    def __init__(self, frame, tokenizer, max_length=64):
        self.texts = frame["document"].tolist()
        self.labels = frame["label"].tolist()
        self.tokenizer = tokenizer
        self.max_length = max_length

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, index):
        ids = self.tokenizer.encode(self.texts[index]).ids[:self.max_length]
        return ids, self.labels[index]

def collate_fn(batch):
    ids_list, labels = zip(*batch)
    max_len = max(len(ids) for ids in ids_list)
    padded = [ids + [0] * (max_len - len(ids)) for ids in ids_list]
    return torch.tensor(padded, dtype=torch.long), torch.tensor(labels)

loader = DataLoader(
    NSMCDataset(train_df, tokenizer), batch_size=64,
    shuffle=True, collate_fn=collate_fn
)

class RNNClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden_dim=256):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, 1)

    def forward(self, input_ids):
        embedded = self.embedding(input_ids)
        _, hidden = self.rnn(embedded)
        return self.fc(hidden[-1]).squeeze(-1)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = RNNClassifier(tokenizer.get_vocab_size()).to(device)
criterion = nn.BCEWithLogitsLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

model.train()
for input_ids, labels in loader:
    input_ids = input_ids.to(device)
    labels = labels.float().to(device)
    optimizer.zero_grad()
    logits = model(input_ids)
    loss = criterion(logits, labels)
    loss.backward()
    optimizer.step()
print(float(loss))
```

## 핵심 해설

- DataFrame → 샘플별 ID 리스트 → 배치 텐서 → 로짓 → 손실 순으로 데이터가 전달된다.
- `Dataset.__getitem__`은 가변 길이 리스트를 반환하고, `collate_fn`이 배치 단위 패딩을 담당한다.
- `nn.RNN(..., batch_first=True)` 입력은 `(batch, length, embed_dim)`, `hidden[-1]`은 `(batch, hidden_dim)`이다.
- `BCEWithLogitsLoss`에는 float 레이블과 sigmoid 이전 로짓을 전달한다.
- 고정 길이 패딩으로 바꾸려면 `Dataset`에서 64까지 채우고 `collate_fn`을 단순화한다.

## 문제 3. LSTM에 Luong Attention 결합

LSTM의 모든 시점 출력과 마지막 은닉 상태를 이용해 Attention 기반 분류를 수행한다. 다음 데이터 흐름에서 빠진 연산 ㉠~㉣을 작성하라.

## 요구사항

- `outputs` shape는 `(B, L, H)`, 마지막 은닉 상태 `query`는 `(B, H)`이다.
- Luong dot attention을 사용한다.
- 가중치는 길이 축의 합이 1이어야 한다.
- 분류기에는 `query`와 문맥 벡터를 이어 붙인 `(B, 2H)`를 전달한다.

## 제공 코드 또는 스켈레톤

```python
outputs, (hidden, cell) = lstm(embedded)
query = ㉠
scores = ㉡
weights = ㉢
context = ㉣
logits = classifier(torch.cat([query, context], dim=-1))
```

## 정답 코드

```python
import torch
from torch import nn

class LuongAttention(nn.Module):
    def forward(self, query, values):
        scores = torch.bmm(values, query.unsqueeze(2)).squeeze(2)
        weights = torch.softmax(scores, dim=1)
        context = torch.bmm(weights.unsqueeze(1), values).squeeze(1)
        return context, weights

class AttentionClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden_dim=256, num_classes=2):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.attention = LuongAttention()
        self.dropout = nn.Dropout(0.3)
        self.classifier = nn.Linear(hidden_dim * 2, num_classes)

    def forward(self, input_ids):
        embedded = self.embedding(input_ids)
        outputs, (hidden, _) = self.lstm(embedded)
        query = hidden[-1]
        context, weights = self.attention(query, outputs)
        combined = torch.cat([query, context], dim=-1)
        return self.classifier(self.dropout(combined)), weights

model = AttentionClassifier(vocab_size=100)
logits, weights = model(torch.randint(0, 100, (4, 12)))
print(logits.shape, weights.shape, weights.sum(dim=1))
```

## 핵심 해설

- LSTM의 `outputs`가 key/value, `hidden[-1]`이 query 역할을 한다.
- `bmm` 입력을 맞추기 위해 query는 `(B,H,1)`, weights는 `(B,1,L)`로 잠시 차원을 추가한다.
- 출력은 로짓 `(B,2)`와 해석용 가중치 `(B,L)`이다.
- 양방향 LSTM으로 변경하면 `H` 결합 방식과 분류기 입력 차원을 함께 수정해야 한다.
- PAD를 실제 Attention에서 제외하려면 `input_ids.ne(0)` 마스크로 PAD score를 softmax 전에 매우 작은 값으로 바꾼다.

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer, pipeline

model_name = "distilbert-base-uncased-finetuned-sst-2-english"

classifier = pipeline("sentiment-analysis", model=model_name)
print(classifier("I love this movie!"))

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name)
inputs = tokenizer("This is great!", return_tensors="pt")
model.eval()
with torch.no_grad():
    logits = model(**inputs).logits

class_id = probabilities.argmax(dim=-1).item()
print(model.config.id2label[class_id], probabilities[0, class_id].item())
```

- `softmax(dim=-1)`은 클래스 축의 로짓을 확률로 바꾼다.
- 다른 분류 모델로 바꾸면 `model_name`만 바꾸되, 레이블 의미는 반드시 새 모델의 `config.id2label`로 확인한다.

## 문제 5. BERT·GPT와 Transformer 내부 처리

문장 표현을 얻는 BERT 흐름, 다음 토큰을 생성하는 GPT-2 흐름, 간단한 Pre-LN 블록 흐름을 각각 완성하라.

## 요구사항

- BERT 출력에서는 모든 토큰의 마지막 은닉 상태를 얻는다.
- GPT-2는 패딩 토큰을 EOS 토큰으로 설정하고 최대 20개의 새 토큰을 생성한다.
- Pre-LN 블록은 각 하위층 전에 정규화하고 각 하위층 뒤에 잔차 연결한다.

## 제공 코드 또는 스켈레톤

```text
BERT: 텍스트 → tokenizer → model → ㉠
GPT-2: prompt → tokenizer → ㉡ → generate → decode
Pre-LN: x → ㉢ → attention → 잔차 덧셈 → ㉣ → FFN → 잔차 덧셈
```

## 정답 5

## 정답 코드

```python
import torch
from torch import nn
from transformers import AutoModel, AutoModelForCausalLM, AutoTokenizer

class PreLNBlock(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_dim)
        self.attention = nn.Linear(hidden_dim, hidden_dim)
        self.norm2 = nn.LayerNorm(hidden_dim)
        self.ffn = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 4), nn.GELU(),
            nn.Linear(hidden_dim * 4, hidden_dim),
        )

    def forward(self, x):
        x = x + self.attention(self.norm1(x))
        x = x + self.ffn(self.norm2(x))
        return x

bert_tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
bert = AutoModel.from_pretrained("bert-base-uncased")
bert_inputs = bert_tokenizer("Transformers encode context.", return_tensors="pt")
with torch.no_grad():
    last_hidden_state = bert(**bert_inputs).last_hidden_state
print(last_hidden_state.shape)

gpt_tokenizer = AutoTokenizer.from_pretrained("gpt2")
gpt = AutoModelForCausalLM.from_pretrained("gpt2")
gpt_tokenizer.pad_token = gpt_tokenizer.eos_token
gpt_inputs = gpt_tokenizer("Artificial intelligence will", return_tensors="pt")
with torch.no_grad():
    generated = gpt.generate(
        **gpt_inputs, max_new_tokens=20,
        pad_token_id=gpt_tokenizer.eos_token_id,
    )
print(gpt_tokenizer.decode(generated[0], skip_special_tokens=True))

block = PreLNBlock(hidden_dim=32)
print(block(torch.randn(2, 5, 32)).shape)
```

## 핵심 해설

- BERT encoder의 `last_hidden_state`는 `(batch, length, hidden)`이며 문맥화된 토큰 표현이다.
- GPT-2 causal LM은 입력 ID를 받아 입력 뒤에 생성 ID를 붙여 반환한다.
- `max_new_tokens`는 입력 길이와 무관한 생성 토큰 수 제한이다.
- Pre-LN은 `x + sublayer(norm(x))`를 두 번 적용한다. 실제 self-attention으로 바꾸려면 현재의 선형층 블록만 교체하면 된다.
- FFN 확장 비율을 바꾸려면 두 Linear의 중간 차원을 함께 수정한다.
