## 문제

`784 → 256 → 128 → 10` MLP를 `nn.Sequential`로 정의하라. 첫 두 선형층 뒤에는 ReLU를, 첫 활성화 뒤에는 0.2 드롭아웃을 둔다. 빈칸을 채워라.

## 요구사항

- 최종 출력은 10개 클래스의 로짓이어야 한다.

## 제공 코드 또는 스켈레톤

```python
import torch
import torch.nn as nn

model = nn.______(
    nn.______(784, 256),
    nn.______(),
    nn.______(p=0.2),
    nn.______(256, 128),
    nn.______(),
    nn.______(128, 10),
)

output = model(torch.randn(1, 784))
print(output.shape)
```

## 정답

## 정답 코드

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.2),
    nn.Linear(256, 128),
    nn.ReLU(),
    nn.Linear(128, 10),
)

output = model(torch.randn(1, 784))
print(output.shape)
```

## 핵심 해설

- `Sequential`은 선언된 순서로 출력을 다음 모듈의 입력으로 전달한다.
- `Linear`의 두 인자는 입력/출력 피처 수이고, `Dropout(p)`의 `p`는 학습 중 제거 확률이다.
- 최종 출력은 확률이 아니라 10개 클래스의 로짓이므로 Softmax를 붙이지 않는다.
- 평가 시에는 `model.eval()`로 드롭아웃을 비활성화한다.
- 층을 추가하면 새 `Linear`의 입출력 차원이 양옆 층과 이어지도록 수정한다.
