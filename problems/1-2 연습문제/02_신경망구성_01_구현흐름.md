## 문제

입력 특성 4개를 받아 클래스 3개의 로짓을 출력하는 은닉층 1개짜리 분류 모델을 완성하라. 은닉층은 8차원과 ReLU를 사용한다. 마지막 출력층에는 활성화 함수를 추가하지 않는다.

## 요구사항

- 입력 배치 `(N, 4)`를 받아 로짓 `(N, 3)`을 출력한다.

## 제공 코드 또는 스켈레톤

```python
import torch
import torch.nn as nn

class Classifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.hidden = ________
        self.activation = ________
        self.output = ________

    def forward(self, x):
        x = ________
        return ________

print(Classifier()(torch.randn(2, 4)).shape)
```

## 정답

## 정답 코드

```python
import torch
import torch.nn as nn

class Classifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.hidden = nn.Linear(4, 8)
        self.activation = nn.ReLU()
        self.output = nn.Linear(8, 3)

    def forward(self, x):
        x = self.activation(self.hidden(x))
        return self.output(x)

print(Classifier()(torch.randn(2, 4)).shape)
```

## 핵심 해설

- 순서는 배치 입력 `(N, 4)` → 선형 은닉층 `(N, 8)` → ReLU `(N, 8)` → 로짓 `(N, 3)`이다.
- `nn.Module`을 상속하고 `super().__init__()`로 하위 레이어가 파라미터로 등록된다.
- `nn.Linear(in_features, out_features)`가 각 블록의 입출력 차원을 결정한다.
- `forward()`의 앞 블록 출력이 다음 블록 입력으로 전달된다.
- 클래스 수가 바뀌면 `self.output`의 두 번째 인자만, 은닉 차원이 바뀌면 연결된 두 `Linear` 차원을 함께 수정한다.
