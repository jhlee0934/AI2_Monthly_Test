## 정답 1

### 정답 코드

- (가) `ChatOpenAI(model=..., api_key=..., base_url=...)`로 LLM 초기화
- (나) `llm.invoke([HumanMessage(content=user_input)])`로 호출

```python
import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

load_dotenv()
llm = ChatOpenAI(model="gpt-5-nano", api_key=os.environ["GMS_KEY"],
                 base_url="https://gms.ssafy.io/gmsapi/api.openai.com/v1/")
response = llm.invoke([HumanMessage(content="안녕하세요")])
print(response.content)
```

### 핵심 해설

- `load_dotenv`의 환경 변수 출력이 `ChatOpenAI` 인증 입력으로 전달되고, `invoke`는 `AIMessage`를 반환한다.
- `HumanMessage.content`는 문자열이며 실제 답변 문자열은 `response.content`이다.
- 모델 변경은 `model`, 중계 서버 변경은 `base_url`, 질문 변경은 `HumanMessage.content`를 수정한다.

## 정답 2

### 정답 코드

- (가) `PyMuPDFLoader(...).load()`
- (나) `ChatPromptTemplate.from_template(...)` 및 `prompt | llm`
- (다) `chain.invoke({"context": context, "question": question})`

```python
from langchain_community.document_loaders import PyMuPDFLoader
from langchain_core.prompts import ChatPromptTemplate

documents = PyMuPDFLoader("data/총알배송_서비스 혜택 - 예스24.pdf").load()
context = "\n".join(doc.page_content for doc in documents)
prompt = ChatPromptTemplate.from_template(
    "다음 자료만 근거로 답하세요.\n자료: {context}\n질문: {question}"
)
response = (prompt | llm).invoke({"context": context, "question": "총알배송 혜택은?"})
print(response.content)
```

### 핵심 해설

- 로더 입력은 PDF 경로, 출력은 페이지별 `Document` 리스트다. `page_content`는 문자열, `metadata`는 출처·페이지 정보 딕셔너리다.
- 결합된 문자열과 질문을 프롬프트 변수 이름과 같은 키의 딕셔너리로 전달한다.
- 여러 PDF로 바꾸려면 로딩 블록을 순회 구조로, 긴 문서를 다루려면 결합 블록을 청킹·검색 블록으로 바꾼다.

from typing import List
from langchain_core.documents import Document

def keyword_search(documents: List[Document], keyword: str) -> List[Document]:
    return [doc for doc in documents if keyword in doc.page_content]

results = keyword_search(all_documents, "총알배송")
for doc in results:
    print(doc.metadata, doc.page_content[:100])

### 핵심 해설

## 정답 4

### 정답 코드

- (가) `OpenAIEmbeddings` 초기화

```python
import os
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import Chroma

embeddings = OpenAIEmbeddings(model="text-embedding-3-small",
    api_key=os.environ["GMS_KEY"],
    base_url="https://gms.ssafy.io/gmsapi/api.openai.com/v1/")
vectorstore = Chroma.from_documents(documents=all_documents, embedding=embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
results = retriever.invoke("배송 혜택은?")
```

### 핵심 해설

- 임베딩은 텍스트를 벡터로, Chroma는 `Document`와 벡터를 검색 가능한 저장소로 바꾼다.
- `search_kwargs`는 딕셔너리이며 `k`는 반환할 상위 문서 수다. 질문 문자열을 `invoke`하면 `List[Document]`가 나온다.
- 임베딩 모델을 바꾸면 기존 저장 벡터와 질의 벡터가 호환되도록 인덱싱 블록도 다시 실행해야 한다.

## 정답 5

### 정답 코드

- (가) `RecursiveCharacterTextSplitter` 초기화
- (나) `split_documents`로 청크 생성
- (다) `as_retriever`로 검색기 생성

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma

splitter = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=50,
    separators=["\n\n", "\n", ".", " "]
)
chunks = splitter.split_documents(all_documents)
vectorstore = Chroma.from_documents(chunks, embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
results = retriever.invoke("늦게 도착하면 보상받을 수 있나요?")
```

### 핵심 해설

- `split_documents`는 `List[Document]`를 받아 메타데이터를 보존한 새 `List[Document]`를 반환한다.
- 청크가 Chroma 입력이 되고 검색 결과도 청크 `Document` 목록이다.
- 문맥이 잘리면 `chunk_size`나 `chunk_overlap`, 문서 구조가 다르면 `separators`를 수정한 뒤 벡터 DB를 재생성한다.

## 정답 6

### 정답 코드

- (가) `retrieve`, (나) `generate`, (다) 노드와 엣지 등록, (라) `compile()` 후 `invoke()`

```python
from typing import TypedDict, List
from langchain_core.documents import Document
from langchain_core.prompts import ChatPromptTemplate
from langgraph.graph import StateGraph, START, END

class RAGState(TypedDict):
    question: str
    context: List[Document]
    answer: str

def retrieve(state: RAGState) -> dict:
    return {"context": retriever.invoke(state["question"])}

def generate(state: RAGState) -> dict:
    context = "\n".join(doc.page_content for doc in state["context"])
    prompt = ChatPromptTemplate.from_template(
        "다음 자료를 기반으로 답하세요.\n자료: {context}\n질문: {question}"
    )
    response = (prompt | llm).invoke(
        {"context": context, "question": state["question"]}
    )
    return {"answer": response.content}

graph = StateGraph(RAGState)
graph.add_node("retrieve", retrieve)
graph.add_node("generate", generate)
graph.add_edge(START, "retrieve")
graph.add_edge("retrieve", "generate")
graph.add_edge("generate", END)
app = graph.compile()
result = app.invoke({"question": "총알배송 서비스의 혜택은?"})
print(result["answer"])
```

### 핵심 해설

- 최초 입력 딕셔너리의 `question`이 검색기로 가고, 검색된 `List[Document]`가 `context`에 병합된다. 생성 노드는 이를 문자열로 바꿔 LLM에 보내고 `answer`만 갱신한다.
- 노드 함수는 전체 상태 대신 변경할 필드의 딕셔너리를 반환할 수 있다.
- 검색 수·방식 변경은 retriever, 답변 규칙 변경은 generate의 프롬프트, 실행 순서 변경은 `add_edge` 블록을 수정한다.
