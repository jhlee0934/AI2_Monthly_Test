## 문제 1. Stable Diffusion 이미지 생성

다음은 텍스트에서 재현 가능한 이미지를 생성하는 흐름이다. (A)~(D)를 채우시오.

`모델 ID + dtype` → (A) → `텍스트 프롬프트 + 제외 프롬프트` → (B) → `seed` → (C) → `파이프라인 출력` → (D) → `PIL 이미지 파일`

## 요구사항

- `runwayml/stable-diffusion-v1-5`와 `torch.float16`을 사용한다.
- 프롬프트 충실도는 7.5, 디노이징 단계는 50이다.
- 시드가 같으면 같은 초기 노이즈에서 생성되도록 한다.
- 출력 객체에서 첫 번째 이미지를 꺼내 `generated_image.jpg`로 저장한다.

## 정답 1

- (A) `StableDiffusionPipeline.from_pretrained(...)`로 파이프라인을 로드하고 `.to(device)`로 이동
- (B) 긍정 프롬프트와 `negative_prompt`를 파이프라인 호출 인자로 구성
- (C) `torch.Generator(device=device).manual_seed(seed)`를 만들고 `generator`로 전달하여 추론
- (D) 반환값의 `.images[0]`을 추출하고 PIL의 `.save(...)` 호출

## 정답 코드

```python
import torch
from diffusers import StableDiffusionPipeline

device = "cuda" if torch.cuda.is_available() else "cpu"
pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=torch.float16,
).to(device)

prompt = "a golden retriever puppy, studio photography, soft lighting, 4k, detailed"
negative_prompt = "blurry, low quality, distorted"
generator = torch.Generator(device=device).manual_seed(42)

image = pipe(
    prompt=prompt,
    negative_prompt=negative_prompt,
    guidance_scale=7.5,
    num_inference_steps=50,
    generator=generator,
).images[0]
image.save("generated_image.jpg")
```

## 핵심 해설

- 처리 순서는 파이프라인 로드 → 프롬프트/난수 생성기 준비 → 디노이징 추론 → 이미지 추출·저장이다.
- `prompt`와 초기 노이즈를 만드는 `generator`가 입력되고, 호출 결과의 `images` 리스트에 PIL 이미지가 담긴다.
- 제외 프롬프트 인자명은 `negative_prompt`이다. 원본 실습의 `negative` 표기는 올바른 호출 인자가 아니다.
- 생성 품질·시간 조건이 바뀌면 `num_inference_steps`, 프롬프트 충실도가 바뀌면 `guidance_scale`, 결과의 구도가 바뀌어야 하면 `seed` 또는 프롬프트 블록을 수정한다.

## 문제 2. CLIP Zero-shot 이미지 분류

한 장의 이미지와 세 문장 후보를 CLIP으로 비교한다. 다음 흐름의 (A)~(D)를 채우시오.

`PIL 이미지 + list[str] 후보 문장` → (A) → `dict 형태 모델 입력` → (B) → `logits_per_image` → (C) → `후보별 확률` → (D) → `최종 문장`

## 요구사항

- 모델과 프로세서는 모두 `openai/clip-vit-base-patch32`를 사용한다.
- 문장 길이가 달라도 배치 입력을 구성할 수 있어야 한다.
- 추론 시 기울기를 기록하지 않는다.
- 한 이미지에 대한 후보 문장 방향 확률을 계산하고 최고 확률 문장을 출력한다.

[정답으로 이동](#answer2)

<a id="answer2"></a>

## 정답 2

- (A) `CLIPProcessor(..., return_tensors="pt", padding=True)`로 이미지 전처리와 텍스트 토큰화
- (B) `torch.no_grad()` 안에서 `CLIPModel(**inputs)` 실행
- (C) `outputs.logits_per_image.softmax(dim=1)`로 문장 후보 축 정규화
- (D) `argmax(dim=1).item()`을 후보 리스트의 인덱스로 사용

## 정답 코드

```python
import torch
from PIL import Image
from transformers import CLIPModel, CLIPProcessor

model_id = "openai/clip-vit-base-patch32"
model = CLIPModel.from_pretrained(model_id)
processor = CLIPProcessor.from_pretrained(model_id)

image = Image.open("generated_image.jpg").convert("RGB")
labels = ["a photo of a dog", "a photo of a cat", "a photo of a bird"]
inputs = processor(
    text=labels,
    images=image,
    return_tensors="pt",
    padding=True,
)

with torch.no_grad():
    outputs = model(**inputs)

probs = outputs.logits_per_image.softmax(dim=1)
predicted = labels[probs.argmax(dim=1).item()]
print(predicted)
```

## 핵심 해설

- 프로세서는 `input_ids`, `attention_mask`, `pixel_values` 등이 담긴 딕셔너리형 입력을 만들며 `**inputs`가 이를 모델의 키워드 인자로 푼다.
- 출력 `logits_per_image`의 shape은 `(이미지 수, 텍스트 수)`이다. 한 이미지에서는 `(1, 3)`이다.
- 후보가 바뀌면 `labels`만 바꾸면 된다. 여러 이미지를 한 번에 평가하면 이미지 축도 생기므로 각 행에서 `argmax(dim=1)` 해야 한다.
- 단일 이미지·단일 문장의 raw CLIP score가 필요할 때는 softmax 없이 `logits_per_image.item()`을 반환한다.

## 문제 3. ResNet-50 Top-5 추론

ImageNet 사전학습 ResNet-50으로 이미지 한 장의 Top-5 클래스와 확률을 출력하는 흐름이다. (A)~(D)를 채우시오.

`ResNet50_Weights.IMAGENET1K_V2` → (A) → `PIL 이미지` → (B) → `(1, 3, 224, 224)` → (C) → `(1, 1000) 확률` → (D) → `클래스명·확률 5쌍`

## 요구사항

- 모델과 전처리는 반드시 같은 가중치 객체를 기준으로 구성한다.
- 모델은 평가 모드로 설정하고 기울기 없이 추론한다.
- 클래스 이름을 별도 하드코딩하지 않는다.

## 정답 3

- (A) `models.resnet50(weights=weights).eval()`과 `weights.transforms()` 준비
- (B) 가중치 전처리 후 `.unsqueeze(0)`으로 배치 차원 추가
- (C) 모델 순전파 후 `torch.softmax(logits, dim=1)`
- (D) `.topk(5)` 결과 인덱스를 `weights.meta["categories"]`에 매핑

## 정답 코드

```python
import torch
import torchvision.models as models
from PIL import Image

weights = models.ResNet50_Weights.IMAGENET1K_V2
model = models.resnet50(weights=weights).eval()
preprocess = weights.transforms()
categories = weights.meta["categories"]

image = Image.open("generated_image.jpg").convert("RGB")
batch = preprocess(image).unsqueeze(0)

with torch.no_grad():
    logits = model(batch)
    probabilities = torch.softmax(logits, dim=1)

top_probs, top_indices = probabilities.topk(5, dim=1)
for prob, index in zip(top_probs[0], top_indices[0]):
    print(categories[index.item()], prob.item())
```

## 핵심 해설

- `weights`는 모델 파라미터, 전처리 규격, ImageNet 클래스명을 연결하는 기준 객체다.
- 전처리 출력 `(3, 224, 224)`에 배치 차원을 붙여야 모델 입력 `(1, 3, 224, 224)`가 된다.
- 출력 로짓은 클래스 확률이 아니므로 클래스 축 `dim=1`에 softmax를 적용한다.
- ResNet 버전이나 가중치를 바꾸면 모델 생성뿐 아니라 `weights.transforms()`와 `weights.meta`도 함께 바꿔야 한다.

## 문제 4. 합성 이미지 기반 전이학습

클래스별 폴더에 저장된 합성 이미지로 ResNet-18의 분류 헤드만 학습한다. 흐름의 (A)~(E)를 채우시오.

`data/train/<class>`, `data/test/<class>` → (A) → `ImageFolder` → (B) → `(images, labels)` → (C) → `동결된 ResNet-18` → (D) → `5-class logits` → (E) → `업데이트된 fc`

## 요구사항

- 학습에는 무작위 crop과 좌우 반전을 적용하지만 테스트에는 무작위 증강을 적용하지 않는다.
- 정규화 통계는 ResNet-18 가중치의 전처리 규격을 사용한다.
- 특징 추출부는 동결하고 새 `fc`만 SGD로 학습한다.

[정답으로 이동](#answer4)

<a id="answer4"></a>

## 정답 4

- (A) train/test 용도에 맞는 `transforms.Compose` 구성
- (B) `DataLoader`로 미니배치와 셔플 정책 구성
- (C) 배치를 모델과 같은 device로 이동
- (D) 기존 파라미터 동결 후 `nn.Linear(model.fc.in_features, 5)`로 헤드 교체
- (E) CE 계산 → `zero_grad()` → `backward()` → `step()`

## 정답 코드

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import transforms
from torchvision.datasets import ImageFolder
from torchvision.models import ResNet18_Weights, resnet18

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
weights = ResNet18_Weights.IMAGENET1K_V1
stats = weights.transforms()

train_tf = transforms.Compose([
    transforms.RandomResizedCrop((224, 224)),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(stats.mean, stats.std),
])
test_tf = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(stats.mean, stats.std),
])

train_set = ImageFolder("data/train", transform=train_tf)
test_set = ImageFolder("data/test", transform=test_tf)
train_loader = DataLoader(train_set, batch_size=4, shuffle=True)
test_loader = DataLoader(test_set, batch_size=4, shuffle=False)

model = resnet18(weights=weights)
for parameter in model.parameters():
    parameter.requires_grad = False
model.fc = nn.Linear(model.fc.in_features, len(train_set.classes))
model.to(device)

criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.fc.parameters(), lr=0.01, momentum=0.9)

model.train()
for images, labels in train_loader:
    images, labels = images.to(device), labels.to(device)
    optimizer.zero_grad()
    logits = model(images)
    loss = criterion(logits, labels)
    loss.backward()
    optimizer.step()
```

## 핵심 해설

- 폴더명이 클래스명이 되고 `ImageFolder.class_to_idx`가 정수 라벨 매핑을 만든다. train/test의 클래스 폴더 구성이 같아야 매핑이 일치한다.
- `DataLoader`는 샘플들을 `(images, labels)` 배치로 전달한다. 학습만 `shuffle=True`를 사용한다.
- 새 `fc`는 동결 루프 뒤에 교체했으므로 기본적으로 `requires_grad=True`이며, 옵티마이저에도 `model.fc.parameters()`만 전달한다.
- 클래스 수가 바뀌면 폴더 구성과 `fc`의 출력 크기를 수정한다. 입력 규격이 바뀌면 두 transform 블록을 함께 검토한다.

## 문제 5. Knowledge Distillation 학습

학습된 ResNet-50 Teacher로 ResNet-18 Student를 지식 증류한다. (A)~(F)를 채우시오.

`images` → `Teacher(eval)` → (A) → `teacher_logits` → (B) → `teacher_soft`

`images` → `Student(train)` → `student_logits` → (C) → `student_log_soft`

`teacher_soft + student_log_soft` → (D) → `KL 손실`

`student_logits + hard labels` → (E) → `CE 손실`

`KL 손실 + CE 손실` → (F) → `Student 파라미터 갱신`

## 요구사항

- Teacher에는 기울기가 생기지 않아야 한다.
- Teacher와 Student 모두 같은 temperature를 사용한다.
- KL 손실에는 `batchmean`과 온도 제곱 보정을 적용한다.
- 모방 비중은 `alpha`, 정답 비중은 `1-alpha`이다.

[정답으로 이동](#answer5)

<a id="answer5"></a>

## 정답 5

- (A) `torch.no_grad()` 안에서 Teacher 추론
- (B) `F.softmax(teacher_logits / temperature, dim=1)`
- (C) `F.log_softmax(student_logits / temperature, dim=1)`
- (D) `F.kl_div(..., reduction="batchmean") * temperature**2`
- (E) `nn.CrossEntropyLoss()(student_logits, labels)`
- (F) `alpha * kl_loss + (1-alpha) * ce_loss`를 역전파하고 Student optimizer 실행

## 정답 코드

```python
import torch
import torch.nn.functional as F

teacher_model.eval()
student_model.train()
temperature = 4.0
alpha = 0.7

for images, labels in train_loader:
    images, labels = images.to(device), labels.to(device)

    with torch.no_grad():
        teacher_logits = teacher_model(images)
        teacher_soft = F.softmax(teacher_logits / temperature, dim=1)

    student_logits = student_model(images)
    student_log_soft = F.log_softmax(student_logits / temperature, dim=1)
    kl_loss = F.kl_div(
        student_log_soft,
        teacher_soft,
        reduction="batchmean",
    ) * (temperature ** 2)
    ce_loss = ce_cross_entropy(student_logits, labels)
    loss = alpha * kl_loss + (1 - alpha) * ce_loss

    student_optimizer.zero_grad()
    loss.backward()
    student_optimizer.step()
```

## 핵심 해설

- Teacher의 확률 분포는 정답 클래스 외의 클래스 관계까지 Student에 전달한다.
- `F.kl_div`의 첫 입력은 Student의 로그 확률, 두 번째 입력은 Teacher의 일반 확률이어야 한다.
- CE에는 temperature로 나누지 않은 원본 Student 로짓과 정수형 정답 라벨을 전달한다.
- `temperature`를 바꾸면 양쪽 분포 계산과 제곱 보정이 함께 영향을 받는다. 모방/정답 비중만 바꾸려면 `alpha` 블록만 수정한다.
- Teacher의 파라미터는 동결하고 `eval()`로 유지하며, 옵티마이저에는 Student의 학습 대상 파라미터만 포함해야 한다.
