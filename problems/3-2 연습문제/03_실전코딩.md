```python
import torch
from diffusers import StableDiffusionPipeline

MODEL_ID = "runwayml/stable-diffusion-v1-5"

def generate_image(prompt: str, negative_prompt: str, seed: int, save_path: str):
    device = "cuda" if torch.cuda.is_available() else "cpu"
    pipe = StableDiffusionPipeline.from_pretrained(
        MODEL_ID,
        torch_dtype=torch.float16,
    ).to(device)
    generator = torch.Generator(device=device).manual_seed(seed)
    image = pipe(
        prompt=prompt,
        negative_prompt=negative_prompt,
        guidance_scale=7.5,
        num_inference_steps=50,
        generator=generator,
    ).images[0]
    image.save(save_path)
    return image

image = generate_image(
    "a red sports car on a mountain road, cinematic lighting, detailed",
    "blurry, low quality, distorted",
    42,
    "car_seed42.jpg",
)
print(type(image), image.size)
```

## 핵심 해설

- 입력은 두 프롬프트와 시드이고 파이프라인 출력의 `images[0]`이 최종 PIL 이미지다.
- 시드는 파이프라인 호출 자체가 아니라 초기 노이즈를 공급하는 `Generator`에 전달된다.
- 이미지 수·크기 조건이 바뀌면 파이프라인 호출 블록, 모델/정밀도가 바뀌면 로드 블록을 수정한다.
- 여러 번 호출할 서비스 코드에서는 파이프라인 로드를 함수 밖으로 옮겨 재사용하는 편이 효율적이다.

## 문제 2. CLIP 분류 및 원시 유사도 평가

이미지 경로와 후보 문장 리스트를 받아 각 후보의 확률, 최고 확률 문장, 최고 문장의 raw CLIP score를 반환하는 함수를 구현하시오.

## 요구사항

- `openai/clip-vit-base-patch32` 모델과 프로세서를 사용한다.
- 이미지 전처리와 텍스트 토큰화를 한 번의 processor 호출로 수행한다.
- 추론에는 기울기를 기록하지 않는다.
- 확률은 텍스트 후보 축으로 softmax하여 Python `dict[str, float]`로 반환한다.
- 반환 형식은 `(probability_map, predicted_text, raw_score)`이다.
- 빈 후보 리스트가 들어오면 `ValueError`를 발생시킨다.

## 정답 코드

```python
import torch
from PIL import Image
from transformers import CLIPModel, CLIPProcessor

MODEL_ID = "openai/clip-vit-base-patch32"
model = CLIPModel.from_pretrained(MODEL_ID).eval()
processor = CLIPProcessor.from_pretrained(MODEL_ID)

def classify_with_clip(image_path: str, candidates: list[str]):
    if not candidates:
        raise ValueError("candidates must not be empty")

    image = Image.open(image_path).convert("RGB")
    inputs = processor(
        text=candidates,
        images=image,
        return_tensors="pt",
        padding=True,
    )
    with torch.no_grad():
        outputs = model(**inputs)

    logits = outputs.logits_per_image
    probabilities = logits.softmax(dim=1)[0]
    best_index = probabilities.argmax().item()
    probability_map = {
        text: probability.item()
        for text, probability in zip(candidates, probabilities)
    }
    return probability_map, candidates[best_index], logits[0, best_index].item()

result = classify_with_clip(
    "generated_image.jpg",
    ["a photo of a dog", "a photo of a cat", "a photo of a car"],
)
print(result)
```

## 핵심 해설

- processor 출력 딕셔너리가 이미지와 모든 문장을 한 모델 호출로 전달한다.
- raw score는 절대 확률이 아니다. 후보 집합 내부 비교 확률은 같은 행의 로짓에 softmax를 적용해 얻는다.
- 후보 형식은 순서가 보존되는 `list[str]`이며, 딕셔너리는 같은 순서로 각 확률을 연결한다.
- 여러 이미지로 확장하면 `logits_per_image`의 각 행마다 별도의 확률 지도와 예측을 만들어야 한다.

## 문제 3. 범용 ImageNet Top-k 분류 함수

PIL 이미지와 `k`를 입력받아 ResNet-50의 상위 예측을 `(클래스명, 확률)` 리스트로 반환하는 함수를 구현하시오.

## 요구사항

- `ResNet50_Weights.IMAGENET1K_V2`를 사용한다.
- 전처리와 클래스명은 같은 가중치 객체에서 가져온다.
- 평가 모드와 `torch.no_grad()`를 사용한다.
- `k`는 1 이상 1000 이하만 허용하고, 범위를 벗어나면 `ValueError`를 발생시킨다.
- 결과는 확률 내림차순의 `list[tuple[str, float]]`이어야 한다.

## 정답 3

## 정답 코드

```python
import torch
import torchvision.models as models
from PIL import Image

weights = models.ResNet50_Weights.IMAGENET1K_V2
model = models.resnet50(weights=weights).eval()
preprocess = weights.transforms()
categories = weights.meta["categories"]

def predict_topk(image: Image.Image, k: int = 5) -> list[tuple[str, float]]:
    if not 1 <= k <= len(categories):
        raise ValueError(f"k must be between 1 and {len(categories)}")

    batch = preprocess(image.convert("RGB")).unsqueeze(0)
    with torch.no_grad():
        probabilities = model(batch).softmax(dim=1)

    top_probs, top_indices = probabilities.topk(k, dim=1)
    return [
        (categories[index.item()], probability.item())
        for probability, index in zip(top_probs[0], top_indices[0])
    ]

image = Image.open("generated_image.jpg")
for name, probability in predict_topk(image, 5):
    print(f"{name}: {probability:.2%}")
```

## 핵심 해설

- PIL 이미지 → 가중치 전처리 텐서 → 배치 텐서 → 1000개 로짓 → 확률 → Top-k 순서로 흐른다.
- `topk`가 반환한 인덱스는 `categories` 리스트의 인덱스와 직접 대응한다.
- GPU 추론으로 변경하려면 모델과 배치 텐서를 같은 device로 이동하는 블록을 함께 추가한다.
- 다른 사전학습 가중치로 바꾸면 `weights`, 모델 생성, 전처리, 카테고리의 연결을 유지해야 한다.

## 문제 4. ResNet-18 Linear Probing 학습기

`data/train/<class_name>/...`, `data/test/<class_name>/...` 구조의 데이터로 ResNet-18 분류기를 학습하고 테스트 정확도를 반환하는 함수를 구현하시오.

## 요구사항

- 학습 transform: `RandomResizedCrop(224)`, `RandomHorizontalFlip`, `ToTensor`, ImageNet 정규화.
- 테스트 transform: `Resize((224, 224))`, `ToTensor`, 같은 정규화.
- `ImageFolder`와 batch size 4의 DataLoader를 사용한다. 학습만 셔플한다.
- ImageNet 사전학습 ResNet-18의 기존 파라미터를 모두 동결한 뒤 `fc`를 클래스 수에 맞게 교체한다.
- `fc`만 SGD(`lr=0.01`, `momentum=0.9`)와 CrossEntropyLoss로 3 epoch 학습한다.
- CUDA가 있으면 CUDA를 사용한다.
- 학습 완료 후 테스트 정확도를 0~1 사이 `float`로 반환한다.

## 제공 코드 또는 스켈레톤

    pass

## 정답 4

## 정답 코드

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import transforms
from torchvision.datasets import ImageFolder
from torchvision.models import ResNet18_Weights, resnet18

def train_linear_probe(train_root: str, test_root: str) -> float:
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    weights = ResNet18_Weights.IMAGENET1K_V1
    stats = weights.transforms()

    train_transform = transforms.Compose([
        transforms.RandomResizedCrop(224),
        transforms.RandomHorizontalFlip(),
        transforms.ToTensor(),
        transforms.Normalize(mean=stats.mean, std=stats.std),
    ])
    test_transform = transforms.Compose([
        transforms.Resize((224, 224)),
        transforms.ToTensor(),
        transforms.Normalize(mean=stats.mean, std=stats.std),
    ])

    train_dataset = ImageFolder(train_root, transform=train_transform)
    test_dataset = ImageFolder(test_root, transform=test_transform)
    if train_dataset.class_to_idx != test_dataset.class_to_idx:
        raise ValueError("train/test class mappings must match")

    train_loader = DataLoader(train_dataset, batch_size=4, shuffle=True)
    test_loader = DataLoader(test_dataset, batch_size=4, shuffle=False)

    model = resnet18(weights=weights)
    for parameter in model.parameters():
        parameter.requires_grad = False
    model.fc = nn.Linear(model.fc.in_features, len(train_dataset.classes))
    model.to(device)

    criterion = nn.CrossEntropyLoss()
    optimizer = optim.SGD(model.fc.parameters(), lr=0.01, momentum=0.9)

    for _ in range(3):
        model.train()
        for images, labels in train_loader:
            images, labels = images.to(device), labels.to(device)
            optimizer.zero_grad()
            logits = model(images)
            loss = criterion(logits, labels)
            loss.backward()
            optimizer.step()

    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for images, labels in test_loader:
            images, labels = images.to(device), labels.to(device)
            predictions = model(images).argmax(dim=1)
            correct += (predictions == labels).sum().item()
            total += labels.size(0)
    return correct / total

accuracy = train_linear_probe("data/train", "data/test")
print(f"accuracy={accuracy:.2%}")
```

## 핵심 해설

- transform → ImageFolder → DataLoader → 모델 입력의 순서로 이미지와 라벨이 전달된다.
- `class_to_idx`는 `dict[str, int]`이며 train/test에서 같아야 정확도 비교가 의미 있다.
- 동결 후 교체된 `fc`만 optimizer에 전달되므로 Linear Probing이 된다.
- 전체 미세조정 조건으로 바뀌면 `requires_grad` 정책과 optimizer 대상이 핵심 수정 지점이다. 클래스 수가 바뀌면 폴더를 기준으로 `fc.out_features`가 자동 변경된다.

## 문제 5. 한 에폭 Knowledge Distillation 함수

학습이 끝난 Teacher와 학습 대상 Student를 받아 한 에폭 동안 지식 증류하는 `train_kd_epoch` 함수를 구현하시오.

## 요구사항

- 인자는 Teacher, Student, DataLoader, Student optimizer, CE 손실 함수, device, temperature, alpha이다.
- `0 <= alpha <= 1`, `temperature > 0`이 아니면 `ValueError`를 발생시킨다.
- Teacher는 평가 모드, Student는 학습 모드로 설정한다.
- Teacher 추론은 기울기 없이 수행한다.
- Teacher 확률에는 `softmax(logits / temperature)`, Student에는 `log_softmax(logits / temperature)`를 사용한다.
- KL은 `reduction="batchmean"`과 `temperature ** 2` 보정을 사용한다.
- 전체 손실은 `alpha * KL + (1-alpha) * CE`이다.
- 모든 샘플을 기준으로 한 평균 손실을 `float`로 반환한다.

## 제공 코드 또는 스켈레톤

```python
def train_kd_epoch(
    teacher, student, loader, optimizer, ce_loss,
    device, temperature: float = 4.0, alpha: float = 0.7,
) -> float:
    pass
```

## 정답 5

## 정답 코드

```python
import torch
import torch.nn.functional as F

def train_kd_epoch(
    teacher, student, loader, optimizer, ce_loss,
    device, temperature: float = 4.0, alpha: float = 0.7,
) -> float:
    if temperature <= 0:
        raise ValueError("temperature must be positive")
    if not 0 <= alpha <= 1:
        raise ValueError("alpha must be between 0 and 1")

    teacher.eval()
    student.train()
    total_loss = 0.0
    total_samples = 0

    for images, labels in loader:
        images, labels = images.to(device), labels.to(device)

        with torch.no_grad():
            teacher_logits = teacher(images)
            teacher_soft = F.softmax(teacher_logits / temperature, dim=1)

        student_logits = student(images)
        student_log_soft = F.log_softmax(
            student_logits / temperature,
            dim=1,
        )
        distillation_loss = F.kl_div(
            student_log_soft,
            teacher_soft,
            reduction="batchmean",
        ) * (temperature ** 2)
        classification_loss = ce_loss(student_logits, labels)
        loss = alpha * distillation_loss + (1 - alpha) * classification_loss

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        batch_size = labels.size(0)
        total_loss += loss.item() * batch_size
        total_samples += batch_size

    return total_loss / total_samples
```

## 핵심 해설

- 한 배치가 Teacher와 Student 양쪽으로 전달되지만 Teacher 경로는 `no_grad`로 계산 그래프에서 분리된다.
- Teacher 출력 `(batch, classes)`는 일반 확률, Student 출력은 로그 확률이 되어 `F.kl_div`에 순서대로 전달된다.
- CE에는 원본 Student 로짓과 `(batch,)` 정수 라벨을 전달한다. 두 손실의 가중합 하나를 역전파한다.
- `batchmean` 손실은 배치 평균이므로 배치 크기를 곱해 누적한 뒤 전체 샘플 수로 나누어, 마지막 작은 배치까지 올바르게 반영한다.
- temperature 변경은 두 soft 분포와 제곱 보정에 연결되고, 모방 비율 변경은 alpha 가중합 블록에만 연결된다.
