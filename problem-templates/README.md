# 문제 제작 템플릿

`flow.json`, `api.json`, `coding.json` 중 필요한 파일을 새 문제 팩의 `questions/`에 복사한 뒤 값을 수정합니다. 한 JSON 파일에는 문제 객체 하나를 두는 방식을 권장합니다.

API 빈칸은 스켈레톤에 `①`, `②` 같은 원문자 또는 `____[1]`, `____[2]`를 표시합니다. 표시가 처음 등장하는 순서와 `blanks` 배열 순서가 일치해야 합니다. 같은 표시를 반복하면 같은 답을 선택하는 드롭다운이 함께 연동됩니다.

필수 공통 필드는 `id`, `unit`, `type`, `title`, `content`, `requirements`입니다. `id`는 전체 문제 팩 안에서 고유해야 하며 저장된 풀이 상태를 식별하므로 배포 후에는 가급적 변경하지 않습니다.

작성 후 프로젝트 루트에서 다음 명령으로 검사합니다.

```powershell
npm.cmd run pack:validate -- my-pack
```
